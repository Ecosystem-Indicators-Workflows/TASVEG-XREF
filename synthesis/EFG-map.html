In order to create spatial outputs from the synthesis of membership values, we need to combine the membership table with the spatial attribute table.

The spatial attribute table attached to the spatial dataset (in Shapefile format) contains one entry per polygon, and hundred of thousands of polygons.

Here we aggregate the data from the second round of expert elicitation.

TASVEG_best_summary <-
    summarise_membership(TASVEG_clean, keep_all = FALSE, which_round = 2)
Round nr. 2 selected.

Then we combine this dataset with the spatial table and a

TASVEG_xy_best <- TASVEG_xy |>
    left_join(TASVEG_best_summary, by = "VEGCODE", relationship = "many-to-one") |>
    left_join(efg_pixel_values, by = "EFG")

TASVEG_raster <- raster(TASVEG_xy, res = rez)

    TASVEG_xy_best,
    TASVEG_raster,
    field = "prop_memb",
    fun = "max"

target_raster <- fasterize(
    TASVEG_xy_best,
    TASVEG_raster,
    field = "efg_pixel_value",
    fun = "first"

    TASVEG_xy_best,
    TASVEG_raster,
    field = "supporting",
    fun = "max"
) |> rast()

    DESCRIPTION = "Synthesis of crossreference from TASVEG to IUCN GET"
)
metags(target_raster) <- rast_metadata

writeRaster(target_raster,
    out_file,
    overwrite = TRUE
)
