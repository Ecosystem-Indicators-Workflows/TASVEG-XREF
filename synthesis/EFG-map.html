13  Spatial outputs

To translate the tabular synthesis from Chapter 11 into spatially explicit maps of IUCN GET Ecosystem Functional Groups across Tasmania, we join our synthesised membership tables to the polygon attribute table of TASVEG 5.0 (TASVEG_5_0.shp) and export either raster GeoTIFFs or vector GeoPackages.

ImportantSeparation of analytical documentation and heavy spatial output generation

Full-state 90 m rasterisation (fasterize) and multi-layer GeoTIFF stack operations take ~2 minutes per run and write large geospatial files. Those production steps are therefore kept in separate standalone scripts (scripts/TASVEG-xref-IUCNGET-output-best-90m.R, scripts/EFG-membership-raster.R, scripts/TASVEG-membership-matrices.R, and scripts/EFG-membership-vector.R; documented in Chapter 17). In this chapter, heavy rasterisation and multi-layer terra::app() chunks are shown with eval: false for transparency, while pre-generated GeoTIFF outputs from results/best-candidate/ are loaded directly for a fast visual preview.

Our setup for this R session loads raster/vector libraries (terra, sf, fasterize), dplyr, readr, ecoSynthesis, and geco (for standard Global Ecosystems Atlas pixel codes and hex colour palettes), and loads the validated membership table:

Setup for this R session 
library(terra)
library(sf)
library(dplyr)
library(readr)
library(ecoSynthesis)
library(geco)
library(fasterize)

here::i_am("synthesis/EFG-map.qmd")
output_dir <- here::here("../results/XREFs")
best_dir <- here::here("../results/best-candidate")
load(here::here(output_dir, "memb-tables.rda"))

efg_pixel_values <- geco_efg_data() |>
    select(efg_code, efg_pixel_value) |>
    rename("EFG" = "efg_code")

The synthesis strategy chosen in Chapter 11 directly determines the structure of the spatial output:

  • Best-candidate (“winner-takes-all”) synthesis (keep_all = FALSE) creates a strict many-to-one join to polygons, allowing the entire state to be represented by three compact 90 m raster layers (best-candidate EFG pixel code, prop_memb, and supporting interpreter count; Output 3 in Chapter 17).
  • All-candidates synthesis (keep_all = TRUE) creates a many-to-many relationship, requiring either one raster layer per candidate EFG (31 GeoTIFFs; Output 2) or a polygon vector GeoPackage for a selected EFG or bundled interpreter matrices (Output 1 and Derived Outputs in Chapter 17).

13.2 Best-candidate synthesis join

Here we aggregate Round 2 assessments to a single best-candidate EFG per VEGCODE via ecoSynthesis::summarise_membership(keep_all = FALSE, which_round = 2):

TASVEG_best_summary <-
    summarise_membership(TASVEG_clean, keep_all = FALSE, which_round = 2)
Round nr. 2 selected.

Next, we join TASVEG_best_summary onto TASVEG_xy (many-to-one on VEGCODE) and attach the standard Global Ecosystems Atlas integer pixel codes (efg_pixel_value) from geco::geco_efg_data():

TASVEG_xy_best <- TASVEG_xy |>
    left_join(TASVEG_best_summary, by = "VEGCODE", relationship = "many-to-one") |>
    left_join(efg_pixel_values, by = "EFG")

13.3 Rasterisation workflow (illustrative; executed separately)

The code block below illustrates how the standalone script scripts/TASVEG-xref-IUCNGET-output-best-90m.R rasterises TASVEG_xy_best onto a 90 m × 90 m grid (EPSG:28355) using fasterize::fasterize()—chosen over terra::rasterize() based on the speed benchmarks in Chapter 16—attaches the official Global Ecosystems Atlas colour table (coltab()) and GDAL metadata tags (metags()), and writes the GeoTIFFs. It is marked eval: false so it is not re-executed during book rendering:

rez <- 90
TASVEG_raster <- raster::raster(TASVEG_xy, res = rez)

# Rasterise best-candidate membership proportion, EFG pixel code, and support count
memb_raster <- fasterize(
    TASVEG_xy_best,
    TASVEG_raster,
    field = "prop_memb",
    fun = "max"
) |> rast()

target_raster <- fasterize(
    TASVEG_xy_best,
    TASVEG_raster,
    field = "efg_pixel_value",
    fun = "first"
) |> rast()

supp_raster <- fasterize(
    TASVEG_xy_best,
    TASVEG_raster,
    field = "supporting",
    fun = "max"
) |> rast()

# Embed Global Ecosystems Atlas colour table and GDAL metadata tags
ctab <- geco_efg_data() |> transmute(value = efg_pixel_value, color = efg_hex_code)
coltab(target_raster) <- ctab

rast_metadata <- c(
    PROJECT = "Ecosystem Indicators Workflows",
    TITLE = "Best candidate ecosystem functional group",
    DESCRIPTION = "Synthesis of crossreference from TASVEG 5.0 to IUCN GET"
)
metags(target_raster) <- rast_metadata

writeRaster(
    target_raster,
    here::here(best_dir, "TASVEG-xref-target.tiff"),
    overwrite = TRUE
)

13.4 Preview of pre-generated 90 m best-candidate GeoTIFFs

Rather than repeating the rasterisation step, the lightweight chunk below loads the pre-generated GeoTIFFs from results/best-candidate/ (published on Zenodo as Ferrer-Paris et al. (2026); see Chapter 17) and displays the best-candidate EFG map alongside its spatial certainty layer (prop_memb):

target_tif <- here::here(best_dir, "TASVEG-xref-target.tiff")
memb_tif <- here::here(best_dir, "TASVEG-xref-membership.tiff")
lut_csv <- here::here(best_dir, "IUCN-GET-pixel-lookup.csv")

if (file.exists(target_tif) && file.exists(memb_tif)) {
    r_target <- rast(target_tif)
    r_memb <- rast(memb_tif)

    if (file.exists(lut_csv)) {
        efg_lut <- read_csv(lut_csv, show_col_types = FALSE)
        levels(r_target) <- data.frame(
            id = efg_lut$efg_pixel_value,
            EFG = efg_lut$EFG
        )
    }

    old_par <- par(mfrow = c(1, 2), mar = c(3, 3, 3, 4))
    plot(r_target, main = "Best-candidate IUCN GET EFG (90 m)")
    plot(r_memb, main = "Membership proportion (prop_memb)")
    par(old_par)
} else {
    message("Pre-generated GeoTIFFs not found in results/best-candidate/; run scripts/TASVEG-xref-IUCNGET-output-best-90m.R first.")
}

13.5 Multi-layer EFG membership raster stacks (illustrative)

When all 31 candidate EFGs are rasterised separately into individual 90 m membership layers (scripts/EFG-membership-raster.R → results/efg-membership-rasters/; Output 2 in Chapter 17), the full stack can be read into terra to cross-check the dominant layer index (which.max) and maximum membership (max) per pixel across all layers. Because pixel-wise terra::app() over 31 statewide 90 m rasters is computationally slow, these diagnostic commands are shown with eval: false:

efg_rast_dir <- here::here("../results/efg-membership-rasters")
tas_all <- rast(dir(efg_rast_dir, pattern = "-memb-90m\\.tiff$", full.names = TRUE))

# Identify which EFG layer achieves the highest prop_memb at each 90 m pixel
tas_which <- app(tas_all, fun = "which.max", na.rm = TRUE)
plot(tas_which, main = "Layer index of maximum EFG membership")

# Compute the maximum prop_memb value across all 31 candidate EFG layers
tas_max <- app(tas_all, fun = "max", na.rm = TRUE)
plot(tas_max, main = "Maximum EFG membership across all 31 layers")
