4  Lookup tables for both classifications

For the next steps of this workflow we will need lookup tables with the valid units of both classifications.

4.0.1 TASVEG

For the TASVEG classification we can explore the look up table to display the basic information for each unit.

Our setup for this R session is:

here::i_am("preparation/lookup-tables.qmd")
library(foreign)
library(dplyr)
library(readr)
library(ecoSynthesis)
output_dir <- here::here("..", "results", "XREFs")

Make sure to download the data first, see this script for instructions:

## 1. Check if data is already present, and if data is complete:

completed <- FALSE

if ("LIST_TASVEG_50_STATEWIDE" %in% list.files(gisdata)) {
  cat("The folder is already present, ")
  all_files <- list.files(
    here::here(gisdata, "LIST_TASVEG_50_STATEWIDE"),
    recursive = TRUE
  )
  how_many <- length(all_files)
  cat(sprintf("there are %s files in there, ", how_many))
  if (how_many == 71) {
    cat("that sounds about right!, nothing else to do.\n")
    ## if present there is nothing to do,
    completed <- TRUE
  } else {
    if (how_many < 71) {
      cat("files missing?, will proceed to download again.\n")
      completed <- FALSE
    } else {
      cat("that's too many, please check!.\n")
      completed <- TRUE
    }
  }
}

if (!completed) {
  ## 2. Obtaining the original data from www.theLIST.tas.gov.au

  ## This is the source URL at theLIST repository
  data_url <- 'https://listdata.thelist.tas.gov.au/opendata/data/LIST_TASVEG_50_STATEWIDE.zip'

  ## Download to a tempfile
  temp_zip <- tempfile(fileext = ".zip")

  ## very large file (1.7GB) will require sometime to download
  options(timeout = max(300, getOption("timeout")))

  ## Download with wget seems to be more stable
  download.file(
    data_url,
    destfile = temp_zip,
    mode = "wb",
    method = "wget",
    extra = c("-c")
  )

  ## 3. Extract all files from downloaded zip archive

  ## Unzip the selected file
  unzip(
    temp_zip,
    exdir = gisdata
  )
}

Here we flag the units that are deemed not eligible and convert this table into a lookup_tbl object:

not_eligible <- c("OAQ", "OSM", "ORO")
TASVEG <- TASVEG_LUT |>
    mutate(eligible = !(VEGCODE %in% not_eligible)) |>
    lookup_tbl("VEGCODE", "VEGCODE_D", "eligible")

4.0.2 IUCN GET

The IUCN GET controlled vocabulary defines all units in the upper levels of the typology.

We use the version included in the IUCN_GET_LUT data from the ecoSynthesis package and assume all units are eligible and valid:

IUCN_GET <- lookup_tbl(IUCN_GET_LUT, "efg_id", "efg_name")

We save both lookup tables in a file that we can load in later steps of the workflow:

save(TASVEG, IUCN_GET, file = here::here(output_dir, "lookup-tables.rda"))
