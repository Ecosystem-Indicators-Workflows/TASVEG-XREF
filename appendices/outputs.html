## The purpose of this script is to create a spatial output from source
## spatial data using cross-referencing information consolidated in
## membership tables.

## Source classification and spatial data (units):

## 1. Overview & Methodology

This dataset provides a **`r res_xy[1]` m resolution spatial synthesis** and **tabular cross-reference lookup tables** aligning Tasmania's statewide vegetation map (**TASVEG 5.0**) with Level 3 **Ecosystem Functional Groups (EFGs)** of the **IUCN Global Ecosystem Typology (IUCN GET)**.

### Cross-Referencing & Expert Elicitation Workflow

Following the IUCN standards and guidelines for cross-referencing ecosystem classifications and maps (IUCN, 2025), the workflow proceeded through four stages:

1. **Conceptual Alignment & Eligibility Assessment:**
   - **Source classification:** TASVEG 5.0 (`LIST_TASVEG_50_STATEWIDE`, released November 2025; Kitchener & Harris, 2013), comprising **`r n_total_units` unique mapping units (`VEGCODE`)** in the statewide polygon shapefile across mainland Tasmania and surrounding islands.
   - **Eligibility:** **`r n_eligible_units` mapping units** represent ecological vegetation communities or anthropogenic/modified ecosystems eligible for cross-referencing to the IUCN GET. **`r n_ineligible` mapping units** in the group *Other natural environments* (`r ineligible_list`) represent broad mapping complexes combining multiple distinct ecosystem types or non-vegetated substrates that cannot be unambiguously aligned to a single ecosystem concept without auxiliary spatial data; these `r n_ineligible` units are flagged as `eligible = FALSE` and assigned `NoData` (`NA`) in the spatial rasters. *(Note: Three additional codes present in the TASVEG 5.0 Fire Attributes DBF lookup table—`FPL`, `HUE`, and `SLW`—do not occur as polygons in the statewide shapefile).*
   - **Target classification:** IUCN Global Ecosystem Typology (Keith et al., 2022) at **Level 3: Ecosystem Functional Groups (EFGs)**.

2. **Two-Round Structured Expert Elicitation:**
   - `r n_interp` domain experts (MGT, DAK, AL, AK, JB) independently assessed the fuzzy membership ($0 < \text{memb} \le 1$, summing to $1.0$ per source unit and interpreter) of each eligible TASVEG 5.0 community across candidate IUCN GET EFGs.
   - Discrepancies and contested units from **Round 1** were systematically reviewed in group discussions, after which experts provided revised assessments in **Round `r round_nr`**.

3. **Synthesis ("Best Candidate" / Winner-Takes-All):**
   - Using the validated **Round `r round_nr`** assessments across all **`r n_interp` interpreters**, membership scores were aggregated by `VEGCODE` using `ecoSynthesis::summarise_membership(..., keep_all = FALSE, which_round = 2)`.
   - For each source `VEGCODE`, the candidate EFG receiving the highest **proportion of total membership votes (`prop_memb`)** across the `r n_interp` interpreters was selected as the **best candidate**.
   - Across the `r n_eligible_units` eligible TASVEG 5.0 units, **`r n_efgs` IUCN GET Ecosystem Functional Groups** were selected as best candidates, with `prop_memb` ranging from **`r sprintf("%.2f", prop_min)` to `r sprintf("%.2f", prop_max)`** (median **`r sprintf("%.2f", prop_median)`**, mean **`r sprintf("%.3f", prop_mean)`**). For **`r supp_max_row$n_units` of `r n_eligible_units` units** (`r sprintf("%.1f%%", supp_max_row$pct_area)` of mapped area), all `r supp_max_row$supporting` interpreters assigned non-zero membership to the winning EFG (`supporting = ` `r supp_max_row$supporting`).

4. **Spatial Rasterization (`r res_xy[1]` m GeoTIFFs):**
   - The synthesised table was joined to the TASVEG 5.0 polygon geometries (`TASVEG_5_0.shp`) and rasterized at **`r res_xy[1]` m × `r res_xy[2]` m resolution** in ``r crs_label`` using `fasterize::fasterize()`.
   - Standard integer pixel codes (`efg_pixel_value`) and official hex color tables (`efg_hex_code`) from the Global Ecosystems Atlas (`geco` R package) were embedded into the target GeoTIFF.

## 2. File Inventory

| File Name | Format | Description |
|---|---|---|
| `TASVEG-xref-target.tiff` | GeoTIFF (`r datatype(r_target)` / integer, embedded color table) | **Best-candidate IUCN GET Ecosystem Functional Group** at `r res_xy[1]` m resolution. Pixel values (``r min(efg_lut$efg_pixel_value)`` to ``r max(efg_lut$efg_pixel_value)``) correspond to `efg_pixel_value` in `IUCN-GET-pixel-lookup.csv`. |
| `TASVEG-xref-membership.tiff` | GeoTIFF (`r datatype(r_memb)` / float32) | **Proportion of total membership votes (`prop_memb`)** supporting the best-candidate EFG in Round `r round_nr` (continuous values from ``r sprintf("%.2f", memb_minmax[1])`` to ``r sprintf("%.2f", memb_minmax[2])``). Quantifies thematic/cross-referencing certainty. |
| `TASVEG-xref-supporting.tiff` | GeoTIFF (`r datatype(r_supp)` / integer) | **Number of supporting interpreters (`supporting`)** out of `r n_interp` who assigned $>0$ membership to the best-candidate EFG in Round `r round_nr` (integer values: `r paste(sprintf("\x60%d\x60", sort(freq_supp$value)), collapse = ", ")`). |

## 3. Spatial Specifications

All three GeoTIFF files (`TASVEG-xref-target.tiff`, `TASVEG-xref-membership.tiff`, `TASVEG-xref-supporting.tiff`) share an identical spatial grid:

| Property | Value |
|---|---|
| **Coordinate Reference System (CRS)** | ``r crs_label`` |
| **Spatial Resolution** | ``r sprintf("%g m × %g m", res_xy[1], res_xy[2])`` (``r sprintf("%.4f km²", pixel_km2)`` / ``r sprintf("%.2f ha", pixel_ha)`` per pixel) |
| **Grid Dimensions** | ``r sprintf("%d rows × %d columns × %d band", n_rows, n_cols, n_bands)`` (``r format(total_cells, big.mark = ",")`` total grid cells) |
| **Mapped Onshore Pixels** | ``r format(mapped_pixels, big.mark = ",")`` valid pixels (``r sprintf("%s km²", format(round(mapped_area_km2, 2), big.mark = ",", nsmall = 2))`` total mapped area) |
| **NoData (`NA`) Pixels** | ``r format(nodata_pixels, big.mark = ",")`` pixels (marine/background outside TASVEG polygons + non-eligible units `OAQ`, `ORO`, `OSM`) |
| **Bounding Box (`xmin, xmax, ymin, ymax`)** | ``r sprintf("%.0f, %.0f, %.0f, %.0f", ext_bbox[1], ext_bbox[2], ext_bbox[3], ext_bbox[4])`` (meters, `r paste0(crs_info$authority[1], ":", crs_info$code[1])`) |
| **Rasterization Rule (`fasterize`)** | `TASVEG-xref-target.tiff`: `fun = "first"` on `efg_pixel_value`<br>`TASVEG-xref-membership.tiff`: `fun = "max"` on `prop_memb`<br>`TASVEG-xref-supporting.tiff`: `fun = "max"` on `supporting` |
| **Embedded GDAL Metadata Tags** | `AREA_OR_POINT = Area`<br>`PROJECT = Ecosystem Indicators Workflows`<br>`DESCRIPTION = Synthesis of crossreference from TASVEG 5.0 to IUCN GET`<br>`TITLE = <Layer-specific title>` |

### Summary of Uncertainty Layers

- **`TASVEG-xref-membership.tiff` (`prop_memb`)**:
  - Represents the proportion of total membership votes across all `r n_interp` interpreters in Round `r round_nr` assigned to the winning EFG:
    $$\text{prop\_memb}_{s, t^*} = \frac{\sum_{i=1}^{`r n_interp`} m_{s, t^*, i}}{\sum_{t} \sum_{i=1}^{`r n_interp`} m_{s, t, i}}$$
  - Values range from **`r sprintf("%.2f", memb_minmax[1])`** (contested/broadly split source unit) to **`r sprintf("%.2f", memb_minmax[2])`** (unanimous 100% assignment by all `r n_interp` interpreters).
- **`TASVEG-xref-supporting.tiff` (`supporting`)**:
  - Count of interpreters (out of `r n_interp` in Round `r round_nr`) who assigned $m_{s, t^*, i} > 0$ to the best-candidate EFG:
```{r}
#| label: supporting-bullets
#| results: asis
for (i in seq_len(nrow(supp_summary))) {
  row <- supp_summary[i, ]
  unit_word <- ifelse(row$n_units == 1, "TASVEG unit", "TASVEG units")
  cat(sprintf(
    "    - `supporting = %d`: **%d %s** (`%s` pixels / `%s km²` / **%.2f%%** of mapped area)\n",
    row$supporting,
    row$n_units,
    unit_word,
    format(row$pixels, big.mark = ","),
    format(round(row$area_km2, 2), big.mark = ",", nsmall = 2),
    row$pct_area
  ))
}
```

## 5. Tabular Data Dictionaries

### `TASVEG-xref-best-candidate.csv` (`r nrow(xref_tbl)` rows × `r ncol(xref_tbl)` columns)

| Column | Type | Description |
|---|---|---|
| `VEG_GROUP` | `string` | Broad TASVEG 5.0 vegetation group name (e.g., `Rainforest and related scrub`, `Dry eucalypt forest and woodland`). |
| `VEGCODE` | `string` | Three-letter TASVEG 5.0 mapping unit code (primary key, e.g., `AAP`, `WDA`). |
| `VEGCODE_D` | `string` | Full name/description of the TASVEG 5.0 community (e.g., `(AAP) Alkaline pans`). |
| `eligible` | `boolean` | `TRUE` for the `r n_eligible_units` cross-referenced vegetation communities; `FALSE` for `OAQ`, `ORO`, and `OSM` (which have `NA` in subsequent columns). |
| `EFG` | `string` | Best-candidate IUCN GET Level 3 Ecosystem Functional Group code (e.g., `TF1.7`, `T2.5`). |
| `efg_name` | `string` | Full name of the best-candidate EFG. |
| `efg_pixel_value` | `integer` | Integer value representing the EFG in `TASVEG-xref-target.tiff` (``r min(efg_lut$efg_pixel_value)`` to ``r max(efg_lut$efg_pixel_value)``). |
| `efg_hex_code` | `string` | Official hexadecimal color code (`#RRGGBB`) from the `geco` package. |
| `efg_rgb_code` | `string` | Comma-separated RGB triplet (`R,G,B`). |
| `round` | `integer` | Expert elicitation round (``r round_nr``). |
| `prop_memb` | `numeric` | Proportion of total Round `r round_nr` membership votes assigned to the best-candidate EFG (``r sprintf("%.2f", prop_min)`` to ``r sprintf("%.2f", prop_max)``). |
| `total_memb` | `numeric` | Total membership weight across all interpreters in Round `r round_nr` (``r n_interp``). |
| `supporting` | `integer` | Number of interpreters in Round `r round_nr` supporting the best-candidate EFG with membership $> 0$ (``r min(xref_elig$supporting)`` to ``r max(xref_elig$supporting)``). |
| `total_interp` | `integer` | Total number of interpreters assessing the unit in Round `r round_nr` (``r n_interp``). |

### `IUCN-GET-pixel-lookup.csv` (`r nrow(efg_lut)` rows × `r ncol(efg_lut)` columns)

| Column | Type | Description |
|---|---|---|
| `efg_pixel_value` | `integer` | Integer pixel code in `TASVEG-xref-target.tiff` (``r min(efg_lut$efg_pixel_value)`` to ``r max(efg_lut$efg_pixel_value)``). |
| `EFG` | `string` | IUCN GET Level 3 code (e.g., `T2.3`). |
| `efg_name` | `string` | Full name of the Ecosystem Functional Group. |
| `realm_id` | `string` | IUCN GET Level 1 Realm code (`r paste(sprintf("\x60%s\x60", unique(efg_lut$realm_id)), collapse = ", ")`). |
| `realm_name` | `string` | IUCN GET Level 1 Realm name. |
| `biome_id` | `string` | IUCN GET Level 2 Functional Biome code (`r paste(sprintf("\x60%s\x60", unique(efg_lut$biome_id)), collapse = ", ")`). |
| `biome_name` | `string` | IUCN GET Level 2 Functional Biome name. |
| `efg_hex_code` | `string` | Hexadecimal color code (`#RRGGBB`). |
| `efg_rgb_code` | `string` | Comma-separated RGB color code (`R,G,B`). |
| `n_tasveg_units` | `integer` | Count of TASVEG 5.0 communities assigned to this EFG as their best candidate. |

## 6. How to Use This Dataset

### In QGIS or ArcGIS
- **QGIS:** Keep `TASVEG-xref-target.qml` in the same folder as `TASVEG-xref-target.tiff`. When you drag and drop `TASVEG-xref-target.tiff` into QGIS, it will automatically apply the official Global Ecosystems Atlas color palette and display both the EFG code and full name in the Layers legend.
- **ArcGIS Pro / GDAL:** Use `TASVEG-xref-target.clr` to import the color map and labels, or join `IUCN-GET-pixel-lookup.csv` on the `Value` = `efg_pixel_value` field.

### In R (`terra`)

```r
library(terra)
library(readr)

# 1. Load the three 90m rasters and lookup table
r_target <- rast("TASVEG-xref-target.tiff")
r_memb   <- rast("TASVEG-xref-membership.tiff")
r_supp   <- rast("TASVEG-xref-supporting.tiff")
lut      <- read_csv("IUCN-GET-pixel-lookup.csv")

# 2. Attach EFG labels as raster factor levels (categorical RAT)
levels(r_target) <- data.frame(
  id = lut$efg_pixel_value,
  EFG = lut$EFG,
  efg_name = lut$efg_name
)

plot(r_target, main = "Best-Candidate IUCN GET Ecosystem Functional Group (90 m)")

# 3. Example: Filter/mask to high-confidence areas (prop_memb >= 0.8 and supporting == 5)
high_conf_mask <- (r_memb >= 0.8) & (r_supp == 5)
r_target_high_conf <- mask(r_target, high_conf_mask, maskvalues = c(0, NA))
```

### In Python (`rasterio` / `pandas`)

```python
import pandas as pd
import rasterio

lut = pd.read_csv("IUCN-GET-pixel-lookup.csv")
xref = pd.read_csv("TASVEG-xref-best-candidate.csv")

with rasterio.open("TASVEG-xref-target.tiff") as src_targ, \
     rasterio.open("TASVEG-xref-membership.tiff") as src_memb:
    efg_arr = src_targ.read(1)
    memb_arr = src_memb.read(1)
    crs = src_targ.crs
    transform = src_targ.transform
```
