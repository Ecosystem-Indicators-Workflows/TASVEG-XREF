16.1 Installing development packages from GitHub

In addition to CRAN packages (dplyr, tidyr, readr, stringr, foreach, foreign, ggplot2, cowplot, DT, sf, terra, fasterize, units, here, XML), this workflow depends on two R packages installed directly from GitHub:

  • Ecosystem-Indicators-Workflows/ecoSynthesis (Ferrer-Paris, Gould, and Singh 2026) — cross-referencing classes, agreement, entropy, plotting, and synthesis functions;
  • Global-Ecosystems-Atlas/geco — standard Global Ecosystems Atlas pixel values and colour tables for IUCN GET functional groups.
pak::pak("Ecosystem-Indicators-Workflows/ecoSynthesis")
pak::pak("Global-Ecosystems-Atlas/geco")
